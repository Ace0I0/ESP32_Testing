## Gray Carrier Signal
APSO-SIGNAL-009
Name: Gray Carrier Signal
Status: active intermittent.
Category: broadcast anomaly.
Description: narrowband tone between stations, strongest near rain, old wood, wet soil, and powered antennas.
Associated hazards: Crawl signal affinity, Fake People voice repetition, Woodcrawler door percussion, false station identification.
Acoustic description: low hum, broken three-note chime, reversed weather report, and a steady carrier tone beneath speech.
Public reports: radios speak before power is connected, television snow forms a doorway shape, emergency tone plays at the wrong hour.

## Reporting Channel Data
Artemis Public Signal Office accepts reports under the following categories:
- unknown voice report
- movement near tree line
- duplicate person report
- plant growth inside structure
- root or bulb report
- red tendril report
- floor vibration report
- signal interference report
- spore or dust report
- missing animal report
- wrong-family-member report
- repeated broadcast report
- station tone report

Report fields:
- name or anonymous status
- location
- time observed
- number of witnesses
- whether a voice was heard
- whether the object moved
- whether contact occurred
- whether signal equipment reacted
- whether the same event has happened before
