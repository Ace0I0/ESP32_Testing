ANALOG BROADCAST STYLE REFERENCE DATA
Common surface format: calm official announcement, short technical label, plain location, simple risk phrase, limited reassurance, unresolved ending.
Common visual atmosphere: degraded tape, centered text, analog snow, color bars, incorrect timestamp, static frame, field recording, public office logo, still photograph with one wrong detail.
Common audio atmosphere: tone burst, warble, detuned chime, tape flutter, dropped syllables, doubled voice, room hum, distorted narrator.
Common narrative structure: normal instructional media becomes increasingly specific, then impossible, then intimate.
Common text fragments: attention viewer, public advisory, official notice, station message, signal record, safety bulletin, observation area, monitoring office, local reporting channel, final notice.
Common tension method: the message avoids panic while the content implies panic is justified.
Common realism method: a fake agency speaks with the structure of a real agency, but the event details are impossible.
Common restraint marker: the broadcast does not scream; it states the impossible as if it is a weather update.
